# 會議錄音轉文字

開會時按下錄音，結束後自動產生**附時間戳記的繁體中文逐字稿**，不用再手寫筆記。

- 🔒 **完全離線**：使用 OpenAI Whisper 開源模型（faster-whisper）在自己電腦上辨識，錄音不會上傳雲端，適合內部會議
- 🎙️ 可直接用麥克風錄音，也可匯入手機錄好的檔案（mp3 / m4a / wav / mp4 …）
- 🀄 自動轉成台灣繁體用語（软件 → 軟體），中英夾雜也能辨識
- 📝 輸出 `.txt` 逐字稿與 `.srt` 字幕檔（可對照錄音回聽）
- 💾 邊錄邊存檔，程式意外關閉也不會遺失錄音

## 安裝（只需做一次）

1. 安裝 [Python 3.10 以上](https://www.python.org/downloads/)（Windows 安裝時勾選 **Add Python to PATH**）
2. 下載本專案，在資料夾中開啟命令列執行：

   ```bash
   pip install -r requirements.txt
   ```

> 第一次辨識時會自動下載語音模型（small 約 500MB），之後就不需要網路。

## 使用方式

### 方法一：圖形介面（推薦）

Windows 直接雙擊 **`啟動.bat`**，或執行 `python app.py`。

1. 按 **● 開始錄音** → 開會
2. 會議結束按 **■ 停止並轉文字**
3. 逐字稿會即時顯示在視窗中，完成後按 **開啟逐字稿**

錄音與逐字稿存在 `使用者資料夾/會議錄音/`。
已經有錄音檔的話，按 **📂 選擇錄音檔轉文字** 即可。

### 方法二：指令列

```bash
# 轉換現有錄音檔（可一次多個）
python meeting_transcriber.py file 週會.m4a 專案會議.mp3

# 用麥克風錄音，按 Ctrl+C 停止後自動轉文字
python meeting_transcriber.py record

# 使用更準的模型、加入專有名詞提示
python meeting_transcriber.py --model large-v3-turbo \
  --prompt "會議逐字稿，繁體中文。出現的名詞：經貿店、POS、KPI" file 會議.m4a
```

## 輸出範例

```
會議逐字稿：會議_20261108_140000.wav
產生時間：2026-11-08 15:02

[00:00:03] 大家好，今天主要討論下一季的行銷預算。
[00:00:09] 第一，請業務部在下週五之前提交報告。
[00:00:15] 第二，產品上市時間延後到十二月。
```

## 模型怎麼選？

| 模型 | 準確度 | 速度（一般筆電 CPU，1 小時會議） | 建議 |
|---|---|---|---|
| `base` | ★★ | 約 5–10 分鐘 | 電腦較舊時 |
| `small` | ★★★ | 約 15–25 分鐘 | **預設，一般筆電** |
| `medium` | ★★★★ | 約 40–60 分鐘 | 不趕時間、要求準確 |
| `large-v3-turbo` | ★★★★★ | 有 NVIDIA 顯卡時只要數分鐘 | 有獨立顯卡首選 |

## 提高準確度的小技巧

- 錄音裝置盡量放在會議桌中央，離說話者近一點
- 在「專有名詞提示」加入公司名稱、產品名、人名，辨識會準很多
- 逐字稿不會區分是誰說話，可依時間戳記回聽確認
