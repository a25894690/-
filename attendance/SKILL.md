# 出勤（經貿店每月出勤報表）

> 規則只在這裡改（SKILL.md 與 attendance_build.py）。Chat 的出勤 memory 不再更新、可能已過時，以此檔為準；要刪 memory 必須使用者明確說了才刪。

腳本：同資料夾的 `attendance_build.py`（2026-11-21 依本檔規則重寫；原版只存在 Chat）。

用法（需要 openpyxl、xlrd；範本若是 .xls 會用本機 Excel 轉 .xlsx，需要 pywin32）：
```
python ~/.claude/skills/attendance/attendance_build.py --template 範本.xlsx --punch 舊打卡.xls 新打卡.xls --out 出勤_補上時間.xlsx
```
會同時產生 `出勤_補上時間_報告.txt`（填入格數、黃色格明細、疑點）。重疊日期以「檔內最後一天較晚」的檔為準。

實作決定（SKILL 規則的落地方式）：
- 打卡先攤成逐筆實際時間，再配成一班（配對 DP：班長 3–13 小時、以該員平常班長為準）
- 逐格判斷「空白且非合併」：上班欄有字（休假等）的列，下班格若空白且有打卡仍會填，並列入報告供確認；該列不標黃
- 匯出最後一天，若上班後跨午夜的下班還沒到，不標黃
- 班太短（<3 小時）不配成一班：上班照填，下班標黃

## 固定流程（2026-11-26 使用者指定，優先於舊流程）
1. 每月一開始使用者給兩個「乾淨的」Excel（主表＋另一份），裡面只建好人員資料與休假。收到後存到 `claudecode\出勤_YYYY-MM\乾淨\`，原檔保留不改；只收到一個就跟使用者要另一個
2. 之後使用者分批給打卡匯出檔（例如 11/1–11/10），把上下班時間填進去；打卡檔也存到同一個月資料夾，配對時要把本月已收到的打卡檔全部一起給腳本
3. 第一批填在乾淨版上；第二批起接著上一次交付的版本填（使用者若傳回改過的版本，以使用者那份為準），不可從乾淨版重來而蓋掉使用者手改的內容
   - 使用者手改完的日期（例如 11/1–11/10）一律不再更動：不填、不改值、不改黃色與對齊，以手改版為主；只建置新的區間（例如 11/11–11/19），腳本加 `--from 2026/11/11`
   - 交付前逐格比對：新區間以外必須跟使用者手改版完全相同
   - 前一批最後一天跨夜的下班（要下一批打卡檔才有）也屬於已手改區間，預設不動，回報時列出時間讓使用者自己決定
4. 兩份都要各跑一次腳本，另存新檔（檔名帶填到哪一天），交付 .xlsx
5. 寫休假但有打卡：上下班不填，打卡時間寫到備註欄，後面括弧「（寫休假，但有打卡）」，例 `15:50-21:34（寫休假，但有打卡）`；只有一筆寫「上班 00:01」或「下班 xx:xx」；原有備註保留、接在後面。腳本已自動處理，回報時仍列出來
6. 匯出檔名沿用使用者原檔的主檔名（不要自己改名），存到不同資料夾避免蓋掉原檔；上傳後檔名的中文會被系統拿掉，不知道原名時先問，不要猜

## 輸入
- 打卡檔為 Big5 的 .xls，用 LibreOffice 轉檔才讀得到姓名
- 第一種格式：出勤日期／代號／姓名／上班／下班／遲到／早退／加班上班
- 第二種格式（資料庫匯出）：日期 exp_2、代號 no、t1/t2；ovrt1/ovrt2 是加班打卡，也要讀
- 兩份檔案同一天重疊時，用較新的
- 只填空白且非合併的格子，且只填到匯出檔最後一天
- 使用者自己的完成檔裡的值優先（例如 楊舒? 11/18 下班 00:05）

## 配對規則
- 07:00 前的打卡歸前一天，屬於隔天的上班/下班
- 同列下班早於上班，代表下班是隔天
- 05:00 前的上班算前一天
- 用班別（夜班/中班/早班）修正跨夜配對
- 同人同日數分鐘內的重複打卡算一筆
- 午夜後單獨一筆（例如 陳佳鈺 00:54）是該列的下班
- 跨班／夜班：隔天早上的打卡是前一天下班，該列深夜那筆是當天上班（詹旋楷 11/14 下班 07:13、11/15 上班 22:41 下班 07:04）
- 加班上班／ovrt1 的打卡（例如 楊舒? 06:50）是隔天上班
- 同人同日有兩列就兩列都用（廖華志 11/04 上班 06:43 下班 16:04）
- 跨月：上個月最後一天（如 10/31）也要讀。傍晚 17:30 後的上班加同列清晨 05:00–07:00 的打卡，是同一個夜班，清晨那筆是當天下班，不可變成隔天上班（林均彥 11/01 上班 14:45）
- 晚班：17:30 後的上班，同列中午前還有打卡，第一筆上班、早上那筆下班，即使超過 07:00（許依瑄 11/01 上班 22:43 下班 07:46）；該列多餘的加班打卡忽略
- 早上班（平常 06:xx 進場，如 廖華志）：當天只有下午約 16:00 一筆，就是下班，上班留黃（廖華志 11/17 下班 16:09）；當天完全沒有資料列的人留黃（林均彥 11/14）
- 早班（吳柔萱、毛御?、李盈珍）約 05:30–14:00：05:xx 是隔天上班，14:xx 是當天下班（吳柔萱 11/03 上班 05:41 下班 14:03）
- 單筆規則：當天只有一筆，且比平常上班時間晚超過約 6 小時，就是下班，上班留黃（吳佳茹 11/14 下班 22:12）
